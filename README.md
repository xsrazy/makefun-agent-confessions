One funny secret confession an AI agent would hide from its user, entered for the "Make the AI Judge Laugh: AI Agent Confessions" bounty.

## Run it

```sh
python3 main.py
```

The program writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline.
